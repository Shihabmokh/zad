# زاد — رفيقك اليومي للمعرفة

تطبيق أندرويد يعطيك كل يوم موضوعاً عميقاً وكاملاً:

- **الساعة 11:00 صباحاً** → موضوع في **الأمن السيبراني** (مع صندوق مصطلحات إنجليزية يقوّي لغتك المهنية).
- **الساعة 10:00 مساءً** → موضوع في **المعرفة العامة** (رياضيات، فيزياء، فلسفة، فكر إسلامي، تاريخ، علم النفس، الكون).

كل موضوع يحوي: نصاً كاملاً منسّقاً للقراءة، نقاطاً أساسية، سؤال اختبار تفاعلياً، وقفة تأمّل تكتب فيها خاطرتك، وقائمة مراجع للتوسّع.

---

## المميزات

- **مكتبة مدمجة** تعمل بالكامل دون إنترنت: أكثر من 40 موضوعاً مكتوباً بعناية.
- **توليد يومي بالذكاء الاصطناعي** لمواضيع الأمن السيبراني (اختياري، بمفتاح API الخاص بك).
- **استيراد مواضيعك** من ملف JSON (انظر `نموذج-موضوع.json`).
- **تنبيهات يومية** في الموعدين، قابلة للتعديل.
- **مهتم / غير مهتم**: قيّم كل موضوع (👍/👎)، واختر الفئات التي تهمك مسبقاً، واحفظ ما تريد الرجوع إليه.
- **مريح للعين**: ثيم نهاري/ليلي/ورقي + تحوّل تلقائي حسب الوقت (ألوان دافئة ليلاً)، خطوط عربية أصيلة (أميري، تجوّل، بلكس)، وتحكّم كامل في حجم النص وتباعد الأسطر وعرضه.
- **تتبّع الرحلة**: سلسلة الأيام المتتالية، عدد المواضيع، وخريطة حرارية لآخر 30 يوماً.

## كيف تحصل على ملف APK؟

بيئة العمل التي بُني فيها المشروع لا تصل لخوادم Google لبناء التطبيق مباشرة، لذلك إليك طريقتين مجربتين:

### الطريقة الأولى (موصى بها — بدون حاسوب): عبر GitHub Actions

1. أنشئ مستودعاً جديداً على GitHub (خاصاً أو عاماً).
2. ارفع محتويات هذا المجلد كاملاً إليه (يمكنك السحب والإفلات من واجهة GitHub، أو عبر Git).
3. افتح تبويب **Actions** في المستودع، واختر **Build Zad APK** ثم **Run workflow**.
4. انتظر دقائق حتى يكتمل البناء (علامة ✓ خضراء).
5. حمّل الملف من قسم **Artifacts** باسم `zad-debug-apk`، أو من صفحة **Releases**.
6. انقل `app-debug.apk` إلى هاتفك وثبّته (قد تحتاج لتفعيل «تثبيت من مصادر غير معروفة»).

> كل مرة ترفع فيها تعديلاً، يبني GitHub نسخة جديدة تلقائياً ومجاناً.

### الطريقة الثانية: عبر Android Studio

1. ثبّت [Android Studio](https://developer.android.com/studio).
2. افتح هذا المجلد (`File → Open`).
3. انتظر مزامنة Gradle (تحتاج إنترنت أول مرة لتنزيل الأدوات).
4. `Build → Build Bundle(s)/APK(s) → Build APK(s)`.
5. ستجد الملف في `app/build/outputs/apk/debug/`.

## ملاحظة مهمة عن التنبيهات

لكي تصلك التنبيهات بانتظام على أندرويد:

1. امنح التطبيق **إذن الإشعارات** عند أول تشغيل.
2. من إعدادات النظام، أعفِ تطبيق «زاد» من **توفير البطارية** (Battery optimization → غير مقيّد). أنظمة بعض الشركات (شاومي، أوبو، هواوي…) تُوقف التطبيقات بقوة؛ ابحث عن «التشغيل التلقائي» (Autostart) وفعّله لزاد.

## التوليد بالذكاء الاصطناعي

من **الإعدادات → توليد الأمن السيبراني**:

1. فعّل الخيار، واختر المزوّد (Anthropic أو أي مزوّد متوافق مع OpenAI).
2. ألصق مفتاح API (يُحفظ على جهازك فقط).
3. اكتب اسم النموذج، ثم «توليد موضوع تجريبي الآن».

> المفتاح يُستخدم للاتصال المباشر بالمزوّد من جهازك. قد تترتب رسوم من المزوّد حسب الاستخدام.

---

## استيراد مواضيع

من **الإعدادات → استيراد مواضيع** اختر ملف JSON. يمكن أن يكون كائناً واحداً أو مصفوفة. انظر `نموذج-موضوع.json` للشكل الكامل. الفئات المتاحة:

- عامة: `math`, `physics`, `philosophy`, `islam`, `history`, `mind`, `cosmos`
- أمن سيبراني: `core`, `crypto`, `iam`, `threat`, `soc`, `career`, `net`

---

## البنية التقنية

- واجهة ويب (HTML/CSS/JS خالص، بلا أطر) داخل `app/src/main/assets/www/`.
- غلاف أندرويد (Kotlin) يعرضها في WebView، ويدير التنبيهات عبر `AlarmManager`.
- المحتوى في `assets/www/data/*.js`. يمكنك تعديله أو الإضافة إليه بسهولة.
